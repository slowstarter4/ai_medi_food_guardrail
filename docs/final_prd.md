# [최종 기능 명세서] SafeEat: AI 기반 복약·식품 가드레일 (MVP)

> **[중요] 본 문서는 MVP(Minimum Viable Product) 수준의 프로토타입 기능을 정의합니다.** 사전에 정의된 약물 목록 및 규칙 범위를 기준으로 설계되었으며, 실제 서비스 시에는 대규모 의약품 DB(DUR 등) 연동이 필수적입니다.

## 1. 프로젝트 비전 및 개요
**SafeEat**은 고령자 및 만성질환자가 약물과 음식, 또는 약물 간의 상호작용으로 인해 발생할 수 있는 위험을 사전에 방지하기 위한 **AI 기반 세이프티 가드레일** 서비스입니다.

### 1.1 배경 및 목적
- **고령층 복약 사고 예방**: 약물 성분과 일상 식단의 상호작용(예: 자몽주스와 고혈압약)에 대한 인지 부족 해결.
- **개인 맞춤형 가이드**: 사용자의 기저 질환(고혈압, 당뇨 등) 및 특수 상황(공복, 음주)을 고려한 정교한 위험 분석.
- **신뢰할 수 있는 근거**: 단순한 경고를 넘어 의학적 기전에 기반한 명확한 행동 지침 제공.

---

## 2. 핵심 기능 상세

### 2.1 하이브리드 성분 인식 엔진
- **OCR 인식**: 처방전, 약 봉투, 약품 패키징 사진을 찍어 성분명을 자동 추출.
- **제네릭/브랜드 매핑**: '아스피린'과 같은 성분명뿐만 아니라 상품명을 `entity_index.json`을 통해 정규화된 성분으로 변환.
- **LLM 보정 및 교정**: OCR 오류(예: '아무로디핀' -> '암로디핀') 혹은 미등록 성분에 대해 GPT-4o-mini가 지능적으로 교정된 표준 이름(`corrected_name`)을 제안하고, 추론 근거와 확신도를 함께 산출.
- **API 교차 검증 (Cross-Check)**: 교정된 이름을 공공 API에 우선 검색하고, 추출된 효능/효과 원문과 추론된 계열 정보를 확장된 키워드 사전(약물 계열별 전문 용어 포함)을 통해 매핑 검증.
- **신뢰성 폴백**: API 검색 결과가 없거나 불분명하더라도 LLM 확신도가 극히 높은 경우(0.95 이상) 조건부 검증 성공 처리.

### 2.2 지능형 위험 분석 (Context Gate)
- **페르소나 컨텍스트**: 사용자가 설정한 질환(고령, 고혈압, 당뇨 등)에 따라 활성화되는 규칙(Ruleset)이 동적으로 결정됨.
- **상황어 감지**: 사용자의 입력 문장에서 '공복', '운동 후', '술 한잔' 등의 키워드를 추출하여 분석에 반영.
- **계층적 규칙 매칭**: 단순 1:1 매칭이 아닌, '성분-성분', '성분-식품', '상태-성분' 등 다각도의 상호작용 검증.

### 2.3 세이프티 리포트 및 근거 시스템
- **3단계 위험 등급**: RED(치명), YELLOW(주의), GREEN(안전)으로 직관적 표시.
- **Evidence-Based Explainer**: RAG 파이프라인을 통해 "원인 -> 위험 -> 행동 지침"의 구조화된 설명을 생성 (70~120자).
- **출처 투명성**: 분석 결과에 사용된 의학적 근거의 출처와 신뢰도(High/Moderate)를 배지로 표기.

---

## 3. 기술 아키텍처 요약

### 3.1 Backend (FastAPI)
- **Ruleset 2.0**: JSON 기반의 선언적 규칙 시스템으로 유지보수 용이성 확보.
- **Normalization Layer**: Fuzzy matching 및 계층형 카테고리 매핑을 통한 높은 엔티티 인식률.
- **RAG Pipeline**: Vector DB를 활용한 의학 지식 검색 및 LLM 기반의 자연어 설명 생성.

### 3.2 Frontend (Next.js)
- **Situation Chips**: 분석 요청 시 사용자의 현재 상태를 실시간으로 커스터마이징할 수 있는 인터페이스.
- **Candidate Correction**: OCR 인식이 불안정할 경우 사용자가 후보군 중에서 올바른 약물을 선택할 수 있는 보정 다이얼로그.

---

## 4. 사용자 경험 (UX) 원칙
1. **신속성**: 분석 버튼 클릭 후 1.5초 이내에 핵심 등급 판정 완료.
2. **명확성**: 전문 용어보다는 사용자 중심의 행동 지침(예: "지금 즉시 물을 많이 마시세요") 우선 노출.
3. **안정성**: 불확실한 데이터에 대해서는 추론(Inferred) 상태임을 명시하여 사용자의 주의 환기.

---

## 5. 향후 확장성
- **STT 통합**: 시각 장애인 및 고령자를 위한 음성 입력 분석 시스템.
- **처방전 이력 관리**: 과거 복약 데이터를 기반으로 한 누적 부작용 예측.
- **약국/병원 연동**: 실제 의료 데이터와의 API 연동을 통한 실시간 데이터 동기화.
